# Vórtex Watermark

Vórtex Watermark, de Vortex Company: aplica tu logo o texto como marca de agua a lotes de imágenes y PDFs, con posición, opacidad, rotación, mosaico y descarga en ZIP. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
